Privacy

Last updated November 19, 2026

The short version

  • No accounts, no ads, no analytics, no tracking.
  • The only thing you type in is a name for other players to see.
  • Games live in the game server's memory while you play and are gone about 20 minutes after everyone leaves.
  • Nothing is sold or shared.

What the game handles

  • Your name. Whatever you type, shown to the other people in your game and in the list of open games. Names with offensive words are replaced with "Player".
  • Your game. The words you trace, scores, votes, alliances and badges, so everyone's screen can show the game. This is kept in memory on the game server, not in a database, and is deleted once a game has sat empty for about 20 minutes.
  • On your device. Your name, the last game you joined (so you can rejoin it), and display choices like which sections you collapsed are saved on your own phone or browser. Deleting the app or clearing the browser's site data removes them.

Services the game relies on

  • Heroku runs the game server. Like any web server it briefly logs requests, which include your IP address.
  • GitHub Pages hosts this website and the game's pages, and sees standard web request details such as your IP address.
  • Google Fonts supplies the game's typeface, so your device asks Google for it when the game loads.

Robggle doesn't send these services anything about you beyond what any web page request includes.

Kids and families

Robggle is a family game. It doesn't ask for ages, emails, contacts, location, photos or anything else personal, so there is nothing about children (or anyone) to collect.
